# 🍽️ Zomato Data Analysis Project

## 📌 Overview
Analysis of Zomato restaurant data to identify insights related to restaurants, ratings, pricing, cuisines, competition, and potential new restaurant locations.

## 🛠️ Tools Used
- Excel
- Pivot Tables
- VLOOKUP
- IF, SUMIF, AVERAGEIF, COUNTIF
- Data Visualization

## 📊 Key Analysis
- Country and city analysis
- Restaurant ratings and votes
- Price range analysis
- Competitor analysis
- Cuisine analysis
- Food expenditure
- Potential locations for new restaurants
